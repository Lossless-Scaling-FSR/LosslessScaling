# Lossless Scaling

**Lossless Scaling** is a Windows app for lossless scaling steam, settings, frame generation and the latest version. LSFG, LS1, FSR, NIS. DXGI or WGC. Any GPU. No Steam client.

## Key Features
- LSFG frame generation: x2, x3, x4
- LS1, FSR, NIS, nearest, bilinear
- NVIDIA, AMD, Intel
- DXGI and WGC capture
- Per-game profiles

## Getting Started
1. Download v3.2.3.
2. Extract `LosslessScaling.zip`.
3. Run `LosslessScaling.exe`.
4. Pick a scale mode or an LSFG multiplier.
5. Set the game to borderless windowed, press the hotkey.

<img width="1200" height="675" alt="images5" src="https://github.com/user-attachments/assets/33c2d270-8585-4b21-8c88-1fd3333300dc" />

## Best settings
- LSFG x2 for 60 to 120 FPS, x3 for high-refresh
- LS1 for pixel-art, FSR for 3D
- WGC when DXGI hooks miss
- Cap the base framerate for stable pacing

## FAQ

**Steam Deck / Linux / Android / Eden?**
This zip is the Windows app. Deck, linux, android, eden and dll notes stay in `files/notes/`.

**Which GPUs?**
Any DirectX 11/12 card. Frame gen is not vendor-locked.

## Requirements
Windows 10/11 64-bit. Any DirectX 11/12 GPU.
